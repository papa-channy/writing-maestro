# 사용자 피드백

writing-maestro가 호출 때마다 읽는다. "사용자 기준"은 사용자가 직접 말한 것이므로 시안 지시의 품질 기준으로 넘긴다. 사이클 기록의 "스킬 관찰"은 시안 지시의 주의 사항과 레지스트리 수정의 근거다.
새 사이클에서 사용자가 시안을 평가하면 "사이클 기록" 아래에 한 절씩 더한다. 사용자가 말하지 않은 기준은 적지 않는다.

## 사용자 기준 (사용자가 직접 말한 것)
- 정보량보다 독자가 판단하는 데 필요한 정보를 골라 배치했는지를 본다. 근거가 많아도 글의 밀도가 과하면 감점("정보량이 많다고 좋은 글이 되는 것은 아니다").
- 발행 준비도를 본다: 가장 적은 수정으로 바로 낼 수 있는 원고를 높게 친다.
- 도입부가 기존 글의 한계를 짚어 이 글이 왜 필요한지 납득시키면 좋게 본다.
- 제목이 약속한 기준과 본문 항목의 성격이 일치해야 한다(선택 기준 목록에 사용법 항목이 섞이면 감점).
- 독자의 실제 상황으로 내려온 구체성(예: 한국어 업무 문서의 높임말·번역투 점검)을 좋게 본다. 독자가 이미 알 법한 조언에 머물면 낮게 본다.
- 출처 링크는 원문을 직접 가리켜야 하고, 링크 표기와 실제 주소가 맞아야 한다.

## 사이클 기록

### 2026-10-30 · 'AI 글쓰기 도구 고르는 법' 한국어 블로그 글, new · 직장인 · 2000자
평가는 사용자가 붙여 넣은 편집 평가(원고 기준, 인용 원문 대조는 하지 않음)다.

| 시안 | 평가 | 사용자 말 |
|---|---|---|
| 조합 2 시안 1 (blog-post-writing → general-writing) | 4위 | 간결하고 단계가 분명하지만 깊이가 부족하다. 짧은 글은 대화형, 긴 글은 문서 앱이라는 기준이 글 길이에만 기댄다 |
| 조합 2 시안 2 (같은 조합) | 1위, 선택 | 독자를 가장 잘 이해한 글. 도입부, 구성 순서, 한국어 업무 문서 점검이 좋다. 수정 문장 수만으로 효율을 재는 점, 가이드 원문 대신 기관 홈페이지 링크는 아쉽다 |
| 조합 3 시안 1 (investigating-sources → blog-post-writing → general-writing) | 2위 | 연구와 실용의 균형이 좋고 한계를 밝혀 신뢰도가 높다. 네 번째 기준이 선택 기준이 아니라 사용법이고, 'CNBC 보도' 표기가 NBC News 링크로 연결된다 |
| 조합 3 시안 2 (같은 조합) | 3위 | 근거가 가장 풍부하고 '문체가 남는가'라는 차별화된 관점이 있다. 논문을 많이 넣은 인상, 기계적인 문단 연결, 일반 독자에게 필요 없는 연구가 섞였다 |

스킬 관찰
- investigating-sources를 앞에 둔 조합: 근거 깊이는 높지만 조사한 연구를 많이 싣는 쪽으로 기울어 실용 가이드의 응집력이 떨어졌다. 블로그·실용 글에서는 "조사한 근거 중 독자 판단에 필요한 것만 고른다"는 선별 지시가 필요해 보인다.
- blog-post-writing → general-writing: 독자 행동 중심 구성과 자연스러운 한국어에서 가장 강했다. 근거를 넣지 않거나 하나만 넣어 깊이와 차별성은 약했다.
- 같은 조합의 두 시안은 품질 차이가 컸다(조합 2는 시안 2, 조합 3은 시안 1이 우세). 시안 하나로 조합의 우열을 판단하지 않는다.
