- NOTES와 결과 어긋남: 조합3-시안1 NOTES "본문 약 2,090자"는 내 계산(링크 표기 포함 약 2,268자)과 약 8% 차이(세는 범위 차이, 사소). 조합3-시안1은 말미에 "원문과 대조해 확인" 고지를 넣었으나 NOTES·조사 메모의 확인 수준(메타데이터·초록)과 다름.

### 시안 간 차별성
- 조합2: 중간 정도. 뼈대(쓸 글 정리 → 규정 확인 → 같은 요청으로 시험 → 결제 판단)는 같지만 시안1은 4단계 절차 + 합니다체 + 한 달 무료 시험 + 제품명 없음, 시안2는 4기준 + 앱 내장형/챗봇 분류 + 제품명 + 해요체 + 2주 시험 + 정부 가이드 인용으로 독자가 받는 정보가 실제로 다르다.
- 조합3: 구조는 쌍둥이에 가깝다. 두 시안 모두 Noy+Dell'Acqua 통계로 열고 1~3기준(시험 / 출처 확인 / 학습 설정)이 거의 같으며 4번째만 갈린다(판단 분리 vs 문체). 차이는 인용 선택(시안1: Walters, 삼성, Lee / 시안2: Brynjolfsson, Ji, Klingbeil, 개인정보위, Jakesch, Agarwal)과 어체(해요체 vs 합니다체), 참고자료 목록 유무에 있다. 서로 독립 조사였는데도 같은 틀로 수렴했다는 점이 관찰된다(조합3의 두 research/brief.md가 모두 같은 탐색 틀을 씀).
